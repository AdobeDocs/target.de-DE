# Erlebnisvorschau für einen [!UICONTROL Multivarianztest] {#preview-mvt-experiences}

>[!BEGINSHADEBOX]

**Auf dieser Seite** Erfahren Sie, wie Sie jedes Erlebnis eines **[!UICONTROL Multivarianz-Tests]** im **[!UICONTROL Visual Experience Composer]** in der Vorschau anzeigen und Erlebnisse ausschließen oder einschließen.

>[!ENDSHADEBOX]

Ein **[!UICONTROL Multivarianz-Test]** (MVT) in [!DNL Adobe Target] vergleicht mehrere Erlebnisse auf einer Seite, daher ist es hilfreich, die Seite mit jedem Erlebnis in der Vorschau anzuzeigen. Die Vorschau zeigt, wie die Angebote in den einzelnen Erlebnissen kombiniert werden, sodass Sie entscheiden können, ob Sie ein Erlebnis ausschließen möchten, bevor der Test live geschaltet wird.

1. Klicken Sie im **[!UICONTROL Visual Experience Composer]** (VEC) auf **[!UICONTROL Vorschau]** und klicken Sie dann auf das Symbol **[!UICONTROL Erlebnisse anzeigen]** ( ![Symbol Erlebnisse anzeigen](/help/main/assets/icons/WebPages.svg) ), um die Liste aller Erlebnisse im linken Rahmen anzuzeigen.

   ![Menü „Bildangebot ändern“](../assets/multivariate-5.png)

1. Klicken Sie auf ein bestimmtes Erlebnis in der Liste, um dieses Erlebnis anzuzeigen.

1. (Optional) Um Erlebnisse auszuschließen oder einzuschließen, klicken Sie auf das Symbol **[!UICONTROL Inhalt verwalten]** ( ![Symbol „Inhalt verwalten](/help/main/assets/icons/Experience.svg) ), um das Dialogfeld **[!UICONTROL Inhalt verwalten]** anzuzeigen.

1. Sie können Erlebnisse ausschließen, die widersprüchliche Varianten aufweisen oder optisch nicht ansprechend wirken. Führen Sie dann einen der folgenden Schritte aus:

   * Um ein Erlebnis auszuschließen, klicken Sie auf das Symbol **[!UICONTROL Mehr Aktionen]** ( ![Symbol Mehr Aktionen](/help/main/assets/icons/MoreSmallList.svg) ) neben dem Erlebnis und dann auf **[!UICONTROL Ausschließen]**.
   * Um mehrere Erlebnisse auszuschließen, aktivieren Sie die Kontrollkästchen für die Erlebnisse und klicken Sie dann auf **[!UICONTROL Ausschließen]**.
   * Um mehrere ausgeschlossene Erlebnisse einzuschließen, aktivieren Sie die Kontrollkästchen für die Erlebnisse und klicken Sie dann auf **[!UICONTROL Einschließen]**.

>[!NOTE]
>
>Beim Erstellen Multivarianz-Tests können Sie mehr als 10 Prozent der Erlebnisse vom Test ausschließen, sofern Sie die Warnung bestätigen, dass Sie dann Offline-Berichte für die Analyse verwenden müssen.
